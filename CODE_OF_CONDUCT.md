# Contributor Covenant Code of Conduct

## Our pledge

Everyone participating in the Sokhan project — issues, pull requests,
Discussions, the Telegram group, the Hugging Face Space — is expected to
keep the space harassment-free, regardless of age, body size, visible or
invisible disability, ethnicity, sex characteristics, gender identity and
expression, level of experience, education, socio-economic status,
nationality, personal appearance, race, religion, or sexual identity and
orientation. Persian and English are both welcome; write in whichever you
prefer.

## Our standards

Positive behavior includes using welcoming language, being patient with
newcomers, publishing reproducible measurements when making claims, and
gracefully accepting constructive criticism. Unacceptable behavior
includes trolling, insulting or derogatory comments, personal or
political attacks, public or private harassment, publishing other
people's private information without consent, and any conduct a
reasonable person would consider inappropriate in a professional
setting.

## Responsibilities

Maintainers are responsible for clarifying the standards and for taking
fair, corrective action in response to any unacceptable behavior, and
have the right and responsibility to remove, edit, or reject comments,
commits, code, issues, and other contributions that violate this Code of
Conduct.

## Scope

This Code of Conduct applies within all project spaces and when an
individual represents the project publicly (for example, using the
project's name on Hugging Face or social media).

## Enforcement

Report abusive, harassing, or otherwise unacceptable behavior privately
via GitHub's [private vulnerability reporting][pvr] channel (choose
"Report a vulnerability" in the Security tab — it reaches the maintainer
directly and stays confidential), or through a direct message to
[@Abolfazlrwm](https://github.com/Abolfazlrwm). All complaints are
reviewed and answered; maintainers bound by confidentiality will
investigate. Violations can result in a temporary or permanent ban from
project spaces.

[pvr]: https://github.com/Abolfazlrwm/sokhan/security/advisories/new
